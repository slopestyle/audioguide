# Фикстуры

`content.sample.json` — единственный источник контента для тестов.

Тесты **не должны** читать `public/content.json`: он меняется при каждой публикации
из админки, и тогда правка названия стенда сотрудником роняет `npm test`, а вместе
с ним сборку и деплой — зал остаётся на старой версии.

Набор стендов подобран под сценарии, менять его без нужды не стоит:

| Стенд | Чем важен |
|---|---|
| 1 | Все четыре языка заполнены |
| 2 | Есть `ru` и `en`, нет `zh` и `ar` |
| 3 | У `en` есть текст, но нет записи — проверка фолбэка на другой язык |
| 10, 11 | Двузначные номера: ввод `1` не должен сразу открывать стенд 1 |
| 12 | Карточка для правок в тестах админки |

Если сценарию нужен новый случай — добавляйте стенд, а не переписывайте
существующие: на их названия опираются проверки.
