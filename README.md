# Аудиогид «Музей друзей»

Веб-аудиогид музея истории Красной Поляны и горнолыжного спорта.
Гость вводит номер стенда и слушает рассказ на своём языке — без установки приложений.

Дизайн и обоснование решений: [project-design.md](project-design.md).
Правила работы с кодом: [CLAUDE.md](CLAUDE.md).

## Запуск

```bash
npm ci
npm run dev      # http://localhost:5173/audioguide/
```

```bash
npm run typecheck   # проверка типов
npm test            # unit + DOM-тесты
npm run lint        # oxlint
npm run build       # сборка в dist/
```

## Публикация

Пуш в `main` запускает GitHub Actions, которые собирают проект и публикуют его
на GitHub Pages: https://slopestyle.github.io/audioguide/

Перед первой публикацией в настройках репозитория нужно включить
**Settings → Pages → Source: GitHub Actions**.

При переезде на собственный домен меняется одна строка — `base` в
[vite.config.ts](vite.config.ts) на `'/'`.

## Контент

Весь контент музея лежит в репозитории и не требует базы данных:

```
public/content.json      номера стендов, тексты и пути к файлам
public/media/<номер>/    ru.mp3, en.mp3, zh.mp3, ar.mp3, фото
```

Сейчас там **демонстрационные данные**: тексты-заглушки и звуковые тоны разной
частоты для каждого языка (чтобы на слух проверять переключение). Настоящий
контент зальётся через админку.

Формат аудио: mp3, 64–96 kbps, моно.

## Обработчик админки

Вход в админку по логину и паролю проверяет маленькая функция в Yandex Cloud
(`server/`). Она же хранит GitHub-токен и делает коммиты — в браузер токен
не попадает. Гостевая часть от неё не зависит.

**Развёртывание:**

```bash
npm run server:hash ivanov "Иван Иванов"   # выдаст пароль и запись для USERS
npm run server:build                       # соберёт dist-server/
```

Дальше в консоли Yandex Cloud: создать функцию (Node.js 22), загрузить
содержимое `dist-server/` архивом, точка входа — `index.handler`, вызов
публичный. Переменные окружения:

| Переменная | Значение |
|---|---|
| `SESSION_SECRET` | случайная строка (например, `openssl rand -base64 32`) |
| `USERS` | JSON-массив записей из `server:hash` |
| `GITHUB_TOKEN` | fine-grained токен: только этот репозиторий, Contents: write |
| `GITHUB_REPO` | `slopestyle/audioguide` |
| `GITHUB_BRANCH` | `main` |
| `ALLOWED_ORIGIN` | `https://slopestyle.github.io` |

Локальная разработка админки — без облака:

```bash
npm run server:dev   # http://localhost:8787
```

## Админка

Адрес: `https://slopestyle.github.io/audioguide/admin/`

Вход по логину и паролю. При первом открытии в поле «Адрес обработчика» нужно
один раз вписать URL функции — он сохранится в браузере.

Как устроена работа: на главном экране матрица готовности (стенды × языки),
клик по строке открывает карточку стенда с вкладками языков. Правки копятся
в черновике и переживают перезагрузку страницы; загруженные файлы живут только
до закрытия вкладки — при попытке уйти браузер предупредит. Кнопка
«Опубликовать» отправляет всё одним коммитом, изменения появляются в зале
примерно через минуту.
